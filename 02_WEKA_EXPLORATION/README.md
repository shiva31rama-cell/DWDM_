# 02. WEKA Exploration

## Aim
Explore WEKA Explorer, Knowledge Flow, Experimenter and CLI; identify attributes, types, record count, class attribute and visualizations.

## Procedure
1. Explorer → Preprocess → Open File.
2. Record relation, instances and attributes.
3. Record every attribute type.
4. Select the class attribute.
5. Plot histograms and inspect class distribution.
6. Use visualization to inspect multiple dimensions.
7. Repeat with Knowledge Flow/Experimenter as required.

## Result
The selected dataset is explored and its structure and visual properties are recorded.
