# Record Guide — Experiment 2

## Aim
Explore WEKA and record dataset information.

## Record in this order
1. Dataset name.
2. Number of instances.
3. Number of attributes.
4. Attribute names.
5. Attribute types.
6. Class attribute.
7. Class counts.
8. Histogram/visualization observation.

## Important
Take the values directly from WEKA. Do not invent the number of records.

## Result
The dataset was explored using WEKA and its structural and visual properties were recorded.
