# Record Guide — Experiment 9

## Aim
Generate frequent itemsets using Apriori.

## Algorithm
1. List individual items.
2. Count their occurrence.
3. Remove items below minimum support.
4. Make pairs.
5. Count pair occurrence.
6. Keep frequent pairs.
