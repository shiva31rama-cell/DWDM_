# Lab Quick Run Guide

## Python

Run a file with:

```bash
python filename.py
```

Python programs in this repository intentionally avoid unnecessary external libraries. Matplotlib is used only where the original visualization experiment requires it.

## Java

Compile:

```bash
javac ClassName.java
```

Run:

```bash
java ClassName
```

## R

For the original R k-means experiment:

```bash
Rscript kmeans.R
```

## WEKA

Follow the numbered experiment's README and RECORD guide.

## Exam/lab strategy

1. Understand the Aim.
2. Learn the 4–8 main theory points.
3. Understand the algorithm in plain language.
4. Read the Python program line by line.
5. Read the Java version.
6. Run the program.
7. Record the output.
8. Write the Result.

Do not memorize complicated code blindly. The code is intentionally kept simple so that you can explain the logic to the lab examiner.
