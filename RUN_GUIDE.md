# Lab Quick Run Guide

## Python
Use Python 3:
```bash
python filename.py
```

## Java
```bash
javac filename.java
java -cp . ClassName
```

## R
```bash
Rscript filename.R
```

## WEKA
Use the GUI procedures in each numbered README. Keep the dataset used by your lab record with the experiment if your faculty requires a specific dataset.

## Important
The sample programs are intentionally simple and heavily readable for lab practice. Replace sample data only when the lab sheet requires a specific dataset.
