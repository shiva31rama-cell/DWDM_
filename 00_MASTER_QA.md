# Quick Revision

**Data Warehouse:** integrated repository used mainly for analysis/reporting.

**OLAP:** analytical processing of multidimensional data.

**Slice:** select one dimension value.  
**Dice:** select a sub-cube using multiple conditions.  
**Roll-up:** detailed data → higher-level summary.  
**Drill-down:** summary → more detail.  
**Pivot:** rotate the multidimensional view.  
**Data Cleaning:** handles missing, noisy, inconsistent and duplicate data.  
**Data Integration:** combines data from multiple sources.  
**Data Reduction:** reduces data volume while preserving useful information.  
**Data Transformation:** converts data into a suitable form for mining.
