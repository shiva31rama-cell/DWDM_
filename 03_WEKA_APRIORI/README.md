# 03. WEKA Cleaning, Preparation and Apriori

## Aim
Prepare data and discover frequent patterns using Apriori with different support/confidence settings.

## Procedure
1. Explorer → Preprocess.
2. Load weather-nominal, Iris or Glass.
3. Inspect missing values and attribute types.
4. Apply Discretize or Resample where required.
5. Associate → Apriori.
6. Change minimum support, confidence and rule count.
7. Run and record strong rules.
8. Compare different settings.

## Result
Frequent itemsets and association rules are obtained after preprocessing.
