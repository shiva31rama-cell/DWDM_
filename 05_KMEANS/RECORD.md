# Record Guide — Experiment 5

## Aim
Cluster data using k-means.

## For each k
Record:
- k value
- Cluster sizes
- Centroids
- Visualization observation

## Algorithm to memorize
1. Choose k centers.
2. Find nearest center for every point.
3. Form clusters.
4. Recalculate centers.
5. Repeat until stable.

## Result
The dataset was grouped into clusters and the effect of different k values was observed.
