# 05. k-Means Clustering

## Aim
Apply k-means with different k values, visualize clusters and explain patterns.

## Procedure
1. Load the dataset.
2. Select SimpleKMeans.
3. Try k = 2, 3 and 4 (or required values).
4. Record cluster sizes and centroids.
5. Visualize clusters.
6. Compare the grouping as k changes.

## Result
The dataset is partitioned into k clusters and characteristics are recorded.
