# Record Guide — Experiment 8

## Aim
Prepare a simulated dataset containing unique instances.

## Algorithm
1. Create an empty dataset.
2. Generate a new record.
3. Compare it with earlier records.
4. If it is new, store it.
5. Repeat until the required number of records is reached.

## Programs
- Java: `code/SimulatedDataset.java`
- Python: `code/simulated_dataset.py`

## Result
A simulated dataset with unique records was generated.
