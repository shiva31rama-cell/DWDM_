# DWDM Lab Programs — Beginner Edition

This repository is the **source of truth** for the DWDM lab.

## What is included

### Programming rule
Where the lab involves programming, the repository provides **both Java and Python** versions whenever practical.

The code is deliberately written for a student who must understand every line:
- basic arrays/lists
- for loops
- while loops where useful
- if/else
- simple variables
- small functions
- comments beside important logic

Unnecessary shortcuts and advanced library calls are avoided.

### Non-coding experiments
The WEKA and schema-based experiments receive extra care:
- Aim
- Theory
- Step-by-step procedure
- What to record
- Observation guidance
- Result
- Viva points where useful

For WEKA experiments, the WEKA procedure remains the main procedure because that is what the supplied lab list asks for. The simple Java/Python demonstrations are supplementary learning aids.

## Recommended lab workflow

1. Open `00_PROGRAM_INDEX.md`.
2. Open the required experiment folder.
3. Read `RECORD.md`.
4. Open the Python and Java files.
5. Understand the algorithm first.
6. Compile/run the language required by your faculty.
7. Copy the output and observation into your record.

## Important
The sample datasets are educational examples. If your faculty gives a specific dataset, use that dataset for the actual lab record.
