# DWDM Lab Programs

Complete practical record for the supplied Data Warehousing and Data Mining lab list.

## Workflow
1. GitHub → **Code → Download ZIP**.
2. Extract the ZIP.
3. Copy the extracted `DWDM_` folder to the pendrive.
4. Open the numbered experiment folder in the lab.
5. Read its README and run the code where provided.

The repository separates WEKA GUI procedures from programming experiments.
