# 07. ZeroR on Iris

## Aim
Demonstrate ZeroR on the Iris dataset using necessary preprocessing and record observations.

## Procedure
1. Explorer → Preprocess → load Iris.
2. Preprocess if required.
3. Classify → ZeroR.
4. Use cross-validation.
5. Record majority-class prediction, accuracy and confusion matrix.
6. Explain that ZeroR does not use predictor attributes; it provides a simple baseline.

## Result
ZeroR produces a baseline classification result based on class distribution.
