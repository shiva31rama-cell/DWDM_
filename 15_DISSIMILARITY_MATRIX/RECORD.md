# Record Guide — Experiment 15

## Aim
Compute and display a dissimilarity matrix for at least four objects with two attributes.

## Formula
For two points (x1,y1) and (x2,y2):

d = √((x1−x2)² + (y1−y2)²)

## Programs
- Python: `code/dissimilarity_matrix.py`
- Java: `code/DissimilarityMatrix.java`

## Observation
The diagonal values are 0 because an object has zero distance from itself. The matrix is symmetric for Euclidean distance.
