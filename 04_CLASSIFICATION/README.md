# 04. Classification

## Aim
Apply ID3/J48, Naive Bayes and k-NN and compare results.

## Procedure
1. Explorer → Classify.
2. Load a dataset and choose its class attribute.
3. Run J48, NaiveBayes and IBk.
4. Use cross-validation.
5. Record accuracy, Kappa, confusion matrix and model/rules.
6. Plot ROC curves where supported.
7. Compare the classifiers.

## Result
Classification models are evaluated and compared using the reported measures.
