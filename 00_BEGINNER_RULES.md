# Beginner Coding Rule — IMPORTANT

Every programming experiment in this repository follows the same rule:

1. **Java + Python** are provided whenever the experiment is a programming exercise.
2. Code is written for a lab student, not for a professional library.
3. Prefer variables, arrays/lists, loops, if/else and small functions.
4. Avoid unnecessary one-line tricks, comprehensions, lambda expressions, external ML libraries and complicated built-in algorithms.
5. Every important logic step has a comment.
6. First understand the manual logic; then use the program.
7. The Python and Java versions should produce the same basic result.

For WEKA-only experiments, the WEKA procedure is kept because that is what the original lab requirement asks for. Simple Python/Java demonstrations are added only to make the concept easier to learn.
